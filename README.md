# AI English Uz

Sun'iy intellekt yordamida ingliz tilini o'rganishga mo'ljallangan veb-platforma.

## 🚀 Loyiha havolasi
- **Veb-sayt:** [aienglishuz.vercel.app](https://aienglishuz.vercel.app/)

## 🛠 Texnologiyalar
Loyihani yaratishda quyidagi texnologiyalardan foydalanilgan:
- Vite
- TypeScript
- React
- Tailwind CSS
- shadcn-ui

## 💻 Mahalliy muhitda (Local) ishga tushirish

Agar loyihani o'z kompyuteringizda ishga tushirmoqchi bo'lsangiz, quyidagi qadamlarni bajaring:

```sh
# 1. Repozitoriyani ko'chirib olish
git clone <SIZNING_GIT_URL>

# 2. Loyiha papkasiga kirish
cd <LOYIHA_NOMI>

# 3. Kerakli paketlarni o'rnatish
npm i

# 4. Dasturni ishga tushirish
npm run dev
